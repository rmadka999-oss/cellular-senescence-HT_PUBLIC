# Twenty representative AIF images

These are the same twenty representative AIF arrays distributed with v1.1.0:
five each for P2, P4, P17 and P27. Original arrays are copied without modification;
file names are simplified. Their SHA256 hashes are listed in [AIF20_INDEX.csv](AIF20_INDEX.csv).

[Archive checksums](SHA256SUMS.txt)

Each ZIP contains five original 2D float32 NPY arrays with physical RI values,
five PNG previews, and a short format note. NPY files preserve quantitative
values; PNG files are for visual inspection only. These arrays are not the
0–1 model-ready inputs required by the public scoring interface.

The images are provided for inspection. The inference-code PolyForm license
does not cover these images. No data license is assigned by this file.
No nuclear masks, weights, fixed score coefficients, original HT volumes,
input-conversion or training sources/settings are included.
